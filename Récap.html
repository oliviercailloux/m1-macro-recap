1. Modèle néo-classique

Modèle de Solow. Avec ou sans progrès technique.

1.1. Dérivées et croissance

Pour toutes fonctions du temps p t , q t et α ∈ ℝ:

  • Notation : p . t = d p t dt

  • Notation : g p t = p . t p t

  • On a : g p t α q t = d ( ln ( p t α q t ) ) dt = d ( α ln p t + ln q t ) dt = α g p t + g q t

  • Il s’ensuit : g p t q t = g p t q t − 1 = g p t − g q t

1.2. Hypothèses

  • F homogène degré 1

  • F ( 0 , 1 ) = 0, ∂ F ∂ K > 0, ∂ F ∂ L > 0, ∂ 2 F ∂ K 2 < 0

  • K t . = s F ( K t , L t ) − δ K t , 0 < s < 1, avec 0 < δ < 1 le taux de dépréciation du capital

  • g L t = n > 0

1.3. Notations

  • k t = K t L t

  • f ( k t ) = F ( K t , L t ) L t

  • c t = ( 1 − s ) f ( k t )

1.4. Déductions

  • k t . = d K t L t dt = K t . L t − K t L t . L t 2 = s f ( k t ) − δ k t − k t n (équation dynamique fondamentale)

  • k t . = 0 ⇔ K t . L t = K t L t . ⇔ g K = n

  • En notant implicitement s = s ( k t ) le taux d’épargne assurant l’état stationnaire en k t , on a k t . = 0 ⇔ s f ( k t ) = k t ( δ + n ) ⇒ d ( s f ( k t ) ) d k t = s f ( k t ) k t

  • d c t d k t = 0 = k t . ⇒ d f ( k t ) d k t = d ( s f ( k t ) ) d k t = s f ( k t ) k t

  • F ( K t , L t ) = K t α L 1 − α ⇒ f ( k t ) = k t α ⇒ d f ( k t ) d k t = α f ( k t ) k t

1.5. Autres concepts et déductions

  • y t = f ( k t )

  • d F ( K t , L t ) d K t = d F ( K t , L t ) d k t d ( K t L t ) d K t = d F ( K t , L t ) L t d k t = d f ( k t ) d k t

  • F K ′ ( K t , L t ) = d F d K t ( K t , L t ) = R t

  • F L ′ ( K t , L t ) = d F d L t ( K t , L t ) = w t

  • r t = R t − δ

2. Modèle de croissance optimale, temps discret

Modèle de Ramsey-Cass-Koopmans

2.1. Croissance

Modèle à temps discret. Soit une fonction du temps p t .

  • Notation : Δ p t = p t + 1 − p t

  • Notation : g p t = Δ p t p t

2.2. Hypothèses

  • F homogène degré 1

  • F ( 0 , 1 ) = 0, ∂ F ∂ K > 0, ∂ F ∂ L > 0, ∂ 2 F ∂ K 2 < 0

  • Δ K t = F ( K t , L t ) − C t − δ K t , avec consommation sociale C t

  • g L t = n > 0, avec L 0 = 1

  • Agent représentatif avec utilité au temps t valant u ( c t ) , avec c t = C t L t , et utilité totale U agent = ∑ 0 ≤ t β t u ( c t ) , avec taux d’escompte psychologique β

2.3. Déductions

  • ( n + 1 ) k t + 1 = f ( k t ) − c t + ( 1 − δ ) k t (équation dynamique fondamentale et contraintes de ressources)

  • On a TMS c t → c t + 1 agent = − d c t d c t + 1 = d U agent d c t + 1 d U agent d c t = β t + 1 u ′ ( c t + 1 ) β t u ′ ( c t ) = β u ′ ( c t + 1 ) u ′ ( c t )

  • Optimum individuel atteint lorsque TMS c t → c t + 1 agent = rapport des prix = p t + 1 p t

  • Utilité sociale U = ∑ 0 ≤ t L t β t u ( c t ) = ∑ 0 ≤ t ( 1 + n ) t β t u ( c t )

  • Programme de l’optimum social : max k t , c t U sous contraintes ∀ t : ( n + 1 ) k t + 1 = f ( k t ) − c t + ( 1 − δ ) k t , lagrangien ∑ 0 ≤ t ( 1 + n ) t β t u ( c t ) − ∑ 0 ≤ t λ t [ ( n + 1 ) k t + 1 − f ( k t ) + c t − ( 1 − δ ) k t ] , d’où ( 1 + n ) t β t u ′ ( c t ) = λ t et ( n + 1 ) λ t − 1 = λ t [ f ′ ( k t ) + ( 1 − δ ) ] , donc λ t λ t − 1 = ( 1 + n ) β u ′ ( c t ) u ′ ( c t − 1 ) = n + 1 f ′ ( k t ) + ( 1 − δ ) , soit β u ′ ( c t ) u ′ ( c t − 1 ) = 1 f ′ ( k t ) + ( 1 − δ )

2.4. Autre notation

  • Posons β = 1 1 + ψ , où ψ est le taux de préférence pour le présent

3. Modèle de croissance optimale, temps continu

3.1. Hypothèses

  • F homogène degré 1

  • F ( 0 , 1 ) = 0, ∂ F ∂ K > 0, ∂ F ∂ L > 0, ∂ 2 F ∂ K 2 < 0

  • g L t = n > 0, avec L 0 = 1

  • Agent représentatif avec utilité au temps t valant u ( c t ) , avec c t = C t L t , avec taux d’escompte psychologique β = 1 1 + ψ

  • Utilité sociale U = ∫ ℝ + e − ( ψ − n ) t u ( c t ) dt

  • K t . = F ( K t , L t ) − C t − δ K t

3.2. Déductions

  • k t . = d K t L t dt = K t . L t − K t L t . L t 2 = f ( k t ) − c t − ( n + δ ) k t (équation dynamique fondamentale, contrainte de ressources)

  • Hamiltonien H t = e − ( ψ − n ) t u ( c t ) + z t ( f ( k t ) − c t − ( δ + n ) k t )

    • d H t d c t = 0 ⇒ e − ( ψ − n ) t u ′ ( c t ) = z t ⇒ g z t = g u ′ ( c t ) + g e − ( ψ − n ) t = g u ′ ( c t ) − ψ + n

    • d H t d k t + z t . = 0 (amélioration marginale compensée par prix marginal du capital au cours du temps), d’où z t . = z t ( δ + n − f ′ ( k t ) )

  • On obtient donc g u ′ ( c t ) = δ − f ′ ( k t ) + ψ

  • k t . = 0 ⇒ c t = f ( k ⋆ ) − ( n + δ ) k ⋆ ⇒ c t . = 0 ⇒ g u ′ ( c t ) = 0 ⇒ f ′ ( k ⋆ ) = δ + ψ

3.3. Autres concepts et déductions

  • g u ′ ( c t ) = ψ − r t

  • Aversion relative au risque (RRA) : − g u ′ ( c t ) g c t ; définissons son inverse comme σ ( c t ) = − g c t g u ′ ( c t )

  • Alors, g c t = σ ( c t ) ( r t − ψ )

  • Avec Constant RRA (CRRA) u ( c t ) = c t 1 − 1 σ 1 − 1 σ , avec σ ∈ ℝ l’inverse de la RRA (une constante), on obtient g c t = σ ( r t − ψ )

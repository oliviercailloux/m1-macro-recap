= Récap Macro — build

== Source

The content lives in `Récap.adoc` (AsciiDoc).

== `Récap.html`

Generated by `Build/`, via `io.github.oliviercailloux.build.Builder`: Asciidoctor converts the `.adoc` to DocBook, which is validated then transformed to HTML by the DocBook xslTNG stylesheet (Saxon).

From `Build/`:

[source,shell]
----
mvn compile exec:java
----

This (re)writes `../Récap.html` and the `../css/` and `../js/` resource folders it links to, plus a `<script>` reference to MathJax (`https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-svg.js`) for formula rendering.

== `Récap standalone.html`

A single self-contained file: same as `Récap.html`, but with `css/docbook.css` and the MathJax script inlined, so it needs neither the `css/`/`js/` folders nor network access to display (nothing else is referenced externally).

The xslTNG stylesheet has no option to emit this directly (it always emits `<link>`/`<script src>`), so it's produced by post-processing `Récap.html`: after regenerating `Récap.html` as above, replace its `<link href="./css/docbook.css" rel="stylesheet" media="screen"/>` element with a `<style>` element containing the content of `css/docbook.css`, and replace its `<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-svg.js" defer="defer"></script>` element with a `<script defer="defer">` element containing the current content fetched from that same URL, then save the result as `Récap standalone.html`.
